SLAM XCAM Studio - Windows Portable Release
============================================

English
-------
1. Extract the entire ZIP archive to a local folder.
2. Run SLAM_XCAM_Studio.exe. Do not move the EXE away from the tools folder.
3. Video processing uses the bundled FFmpeg tools automatically.
4. Camera Management uses the bundled Android Debug Bridge automatically.
5. For camera access, connect SLAM XCAM by USB and authorize USB debugging on the camera.

System requirements: 64-bit Windows 10/11. Current GPU drivers are recommended.
The renderer falls back to CPU when a supported GPU path is unavailable.

中文
----
1. 将 ZIP 压缩包完整解压到本地文件夹。
2. 双击 SLAM_XCAM_Studio.exe。请勿将 EXE 单独移出 tools 文件夹。
3. 视频分析、防抖、拼接和导出会自动使用内置 FFmpeg。
4. 相机管理会自动使用内置 Android Debug Bridge。
5. 连接相机时，请使用 USB 连接 SLAM XCAM，并在相机端允许 USB 调试授权。

系统要求：64 位 Windows 10/11。建议安装最新显卡驱动；GPU 路径不可用时会回退 CPU。

Licenses and third-party notices are stored in the licenses folder.
